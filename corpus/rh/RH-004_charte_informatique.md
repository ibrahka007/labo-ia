# RH-004 — Charte informatique

## 1. Objet

Définir les règles d'usage des systèmes d'information du groupe fictif Asteria.

## 2. Accès

- Un compte nominatif par collaborateur.
- Principe du moindre privilège.
- Les accès sont revus **chaque trimestre** ([DOC-004]).

## 3. Mots de passe

- Longueur minimale : 12 caractères.
- **Renouvellement tous les 90 jours.**
- Authentification multifacteur obligatoire pour les accès distants.

## 4. Usage

- Les données professionnelles restent dans les espaces autorisés.
- L'installation de logiciels non validés est interdite.
- Le télétravail respecte [RH-001].

## 5. Incidents

- Signaler tout incident de sécurité **sous 24 heures**.
- Ne pas tenter de corriger seul une compromission suspectée.

## 6. Références

- [RH-001] Politique de télétravail.
- [DOC-004] Matrice des habilitations documentaires.
